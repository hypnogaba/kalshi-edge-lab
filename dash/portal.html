01

Latency benchmark

Captures the same Kalshi trades two ways on one host — public Kalshi WS and the DoubleZero edge feed — matches each trade by id, and reports the arrival delta. One monotonic clock (CLOCK_MONOTONIC_RAW); no cross-machine timestamps.

run it

# one host, both feeds, N minutes → percentiles + PNG
uv run python -m scripts.run_race \
  --market KXBTC-…-T68500 \
  --group <mcast> --mktdata-port 9601 --refdata-port 9602 \
  --iface <recv-ip> --minutes 10

# output
matched N trades  (match rate …%)
p10 / p50 / p90 / p99   ms   # negative = DoubleZero first

validate the tool offline (no feed, no keys)

$ uv run python -m scripts.run_race --selfcheck

03

Open feed decoder

Consume the DoubleZero Kalshi edge feed directly: join the multicast group, decode the fixed-size binary frames, get normalized events. Verified byte-for-byte against the published edge-feed-spec. The public Kalshi WS decodes to the same Event type — one interface, swappable sources.

decode frames → normalized events

from sources.dz_feed.decoder import DzDecoder
from common.storage import read_frames

dz = DzDecoder()               # holds the instrument registry
for t_ns, pkt in read_frames("dz.bin"):
    for ev in dz.decode(pkt, t_ns):
        ev.kind    # quote | trade
        ev.price   # scaled by instrument exponent
        ev.size; ev.side; ev.seq
