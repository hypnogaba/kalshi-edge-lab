STEP A

The Latency Race

The same Kalshi market on one host, two ways: the public Kalshi WebSocket (direct) vs. the DoubleZero edge feed. Matched trade-for-trade with a millisecond delta on who saw it first.

The Demo Bot

A deliberately simple bot on Kalshi's demo environment. Reads real trades + an exchange reference price, forms a signal, and runs the full pipeline — decision, guardrails, order, dashboard — on paper money.

Matches the same trade across two feeds on one clock, then reports tDZ − tpublic (negative = DoubleZero first). The self-check injects a known +3 ms and recovers it exactly — the tool is honest. Real edge-vs-public numbers land the moment the Kalshi feed runs on the server.

Three data sources behind one Event interface. The DoubleZero edge feed decodes the open binary edge wire format (which supports Kalshi's prediction markets natively); when it runs on the server it drops in as one more source — the race and bot consume it unchanged.
